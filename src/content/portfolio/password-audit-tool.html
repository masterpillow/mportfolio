Password Audit Tool

A Python CLI tool for auditing password lists against NIST SP 800-63B compliance standards. Uses the HaveIBeenPwned API's k-anonymity model to check for breached passwords without exposing the actual credentials, and generates formatted compliance reports.

01 — Background

NIST SP 800-63B requires organizations to check user passwords against known breach corpora during registration and password changes. The HaveIBeenPwned API provides access to over 800 million breached passwords, but sending raw passwords to a third-party API is a security risk. This tool implements the k-anonymity model to check passwords safely.

02 — K-Anonymity Implementation

The key insight: instead of sending the full password hash, we send only the first 5 characters of the SHA-1 hash. The API returns all hashes starting with those 5 characters. We then check locally whether our full hash appears in the response — the API never sees enough to reconstruct our password.

import hashlib, requests def check_pwned(password: str) -> int: """Returns breach count (0 = not found in HIBP)""" # Step 1: SHA-1 hash the password sha1 = hashlib.sha1(password.encode()).hexdigest().upper() prefix, suffix = sha1[:5], sha1[5:] # Step 2: Send ONLY the first 5 chars to HIBP API response = requests.get( f'https://api.pwnedpasswords.com/range/{prefix}', headers={'Add-Padding': 'true'} # extra privacy padding ) # Step 3: Search response locally for our suffix for line in response.text.splitlines(): hash_suffix, count = line.split(':') if hash_suffix == suffix: return int(count) return 0 # not found

05 — Privacy & Design Decisions

  • Passwords are never logged or stored — only processed in memory
  • The k-anonymity model means the HIBP API server cannot reconstruct any tested password even with full request logs
  • Rate limiting built in to respect HIBP's API terms (1500ms between requests in bulk mode)
  • Input accepts plaintext or pre-hashed SHA-1 lists depending on the caller's security posture
  • Report generation is offline — no passwords are included in the HTML output, only statistics
