Network Reconnaissance Toolkit

A modular Python automation framework that orchestrates Nmap scanning, banner grabbing, service enumeration, and Shodan API lookups into a single workflow. Reduces manual recon time by ~60% and outputs structured HTML/JSON reports suitable for client deliverables.

01 — Problem Statement

During engagements, the manual recon phase was consuming 2–3 hours: running Nmap scans, waiting, cross-referencing with Shodan, formatting notes, and building a picture of the attack surface. The goal of this project was to automate that entire pipeline down to a single command.

02 — Architecture

The toolkit is structured as a pipeline of three modules that run sequentially, passing a shared host state object between them:

recon-toolkit/ ├── main.py # entry point, argparse, orchestration ├── modules/ │ ├── scanner.py # nmap wrapper with python-nmap │ ├── shodan_lookup.py # shodan API integration │ ├── banner_grab.py # async socket banner grabbing │ └── vuln_check.py # CVE cross-reference via NVD API ├── report/ │ ├── generator.py # jinja2 HTML report builder │ └── templates/ # report HTML templates └── utils/ ├── logger.py # structured color logging └── validator.py # input sanitization

03 — Key Implementation Details

Nmap Module

The scanner wraps python-nmap to run a staged scan: a fast SYN scan for port discovery, followed by service version detection and script scanning on discovered ports only. This avoids running slow scripts against all 65535 ports.

import nmap from dataclasses import dataclass class NmapScanner: def run(self, target: str) -> dict: nm = nmap.PortScanner() # Phase 1: fast port discovery nm.scan(target, arguments='-T4 -p- --min-rate 5000') open_ports = self._extract_open_ports(nm) # Phase 2: deep scan on discovered ports only port_str = ','.join(str(p) for p in open_ports) nm.scan(target, ports=port_str, arguments='-sV -sC -O --version-intensity 7') return self._parse_results(nm, target)

Async Banner Grabbing

The banner grabbing module uses asyncio to simultaneously connect to all open ports, dramatically reducing total time compared to sequential connections.

async def grab_banner(host: str, port: int, timeout=3) -> str: try: reader, writer = await asyncio.wait_for( asyncio.open_connection(host, port), timeout=timeout ) writer.write(b'HEAD / HTTP/1.0\r\n\r\n') await writer.drain() banner = await asyncio.wait_for(reader.read(1024), timeout=timeout) return banner.decode('utf-8', errors='ignore').strip() except (asyncio.TimeoutError, ConnectionRefusedError): return "" async def grab_all_banners(host: str, ports: list[int]) -> dict: tasks = [grab_banner(host, port) for port in ports] results = await asyncio.gather(*tasks) return dict(zip(ports, results))

Shodan Integration

For internet-facing targets, the Shodan module enriches scan results with historical exposure data, associated CVEs, and open port history that may not be visible from a direct scan (e.g. filtered ports still exposed historically).

import shodan class ShodanLookup: def __init__(self, api_key: str): self.api = shodan.Shodan(api_key) def enrich(self, ip: str) -> dict: try: host = self.api.host(ip) return { 'org': host.get('org', 'Unknown'), 'isp': host.get('isp', 'Unknown'), 'vulns': list(host.get('vulns', [])), 'ports': host.get('ports', []), 'tags': host.get('tags', []), 'last_seen': host.get('last_update') } except shodan.APIError: return {}

05 — Results

Tested against 12 different lab environments. Average recon phase dropped from ~180 minutes to ~72 minutes. The structured JSON output also enabled chaining with other tools like Metasploit's resource scripts for automated exploitation testing.
